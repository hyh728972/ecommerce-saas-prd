## 3. 与 B 端 / PC 对齐

| 维度 | 说明 |
|------|------|
| 资产到账 | B 端选人直充 或 卡密兑换；无 C 端领券中心 |
| 苏银豆账户 | 统一余额，无批次选择；品牌积分换算展示（100 豆 = 1 元） |
| 结算叠加 | **先卡券后苏银豆**，再现金 |
| 卡券范围 | 卡券抽屉 / 结算仅展示订单可用且在使用范围内的券 |
| 积分范围 | 苏银豆抵扣不设品类限制 |
| PC 交互 | 计算逻辑同小程序；交互形态差异见总 PRD §5 开头 |
