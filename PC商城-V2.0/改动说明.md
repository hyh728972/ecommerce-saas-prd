# PC商城在线客服 - 原型增量包改动说明

> 版本：V1.0 ｜ 日期：2026-09-01 ｜ 类型：原型增量交付

本包为 **在线客服功能的原型增量**，可直接双击 HTML 预览（保持目录结构即可，资源为相对路径引用）。

## 一、本次需求范围

新增「在线客服」功能：京东式客服对话页（消息列表 + 聊天主体 + 服务信息三栏），并在商城各核心链路页面增加客服入口，支持按业务场景（订单 / 售后 / 积分 / 账户）自动携带上下文。

详细需求见：`页面原型与PRD/PRD-在线客服需求文档-V1.0.md`

## 四、开发注意事项

1. **`proto-nav.js / proto-nav.css` 是原型评审导航工具，仅供点击预览各页面，无需实现。**
2. 其余 `proto-*`、`*-mock.js` 为原型演示用的假数据与交互，仅供理解交互流程，业务逻辑以后端实现为准。
3. 客服入口统一约定：页面元素带 `data-cs-open` + `data-cs-topic`（order/refund/points/account），部分入口额外携带订单号/商品名。开发实现时可参考此上下文传递方式。
4. 包内商品图片仅保留了本包页面引用的部分（129 张）；如需完整原型图库，以全量包 `商城PC.zip` 为准。
