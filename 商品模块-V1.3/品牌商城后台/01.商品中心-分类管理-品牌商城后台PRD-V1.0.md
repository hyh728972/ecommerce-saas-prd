## 1. 文档概述

### 1.1 项目背景

商城运营平台（商品中心）负责分类结构编排、商品关联、渠道指定和推荐排序，通过发布机制将平台数据推送至各品牌商城后台。品牌商城后台作为各商城的独立管理端，接收平台数据后需进行二次编排——新增营销分类、编辑平台分类名称/图标、隐藏不适用的平台分类，调整最终排序，并通过小程序端预览确认 C 端展示效果。

当前品牌商城后台尚无独立的前台分类管理能力，商城工作人员无法在平台之上做差异化调整。

### 1.2 项目目标

1. **接收与展示平台数据**：接收商品中心推送的分类平台数据（基础分类 + 营销分类），在统一列表中展示，区分"平台"与"自有"来源。
2. **二次编排能力**：商城工作人员可在平台之上新增营销分类、自定义平台分类显示名称、隐藏不适用的平台分类，调整最终排序。
3. **分类商品归属管理**：在分类管理页直接把商品加入/移出某个三级分类（平台/自有均开放），商城侧自主调整 C 端分类导航下的商品。
4. **小程序端预览**：编辑完成后可预览小程序端 C 端分类展示效果。

### 1.3 核心术语

| 术语 | 定义 |
|------|------|
| **平台数据** | 商品中心发布推送的分类数据，品牌商城后台不可删除仅可隐藏 |
| **自有数据** | 品牌商城后台自行创建的营销分类，可增删改 |
| **基础分类** | 商品中心编排的前台导航分类（含系统类目节点和虚拟分类），商城侧不区分来源统一归为基础分类 |
| **营销分类** | 商品中心或商城侧创建的主题活动分类（如"618专区"），商城侧可新增 |
| **分类类型** | 统一列表通过"分类类型"列区分：基础分类 / 营销分类 |
| **来源** | 标识数据来源：平台（商品中心推送）/ 自有（商城自有） |
| **自定义前端显示名称** | 商城侧为平台分类设置的显示覆盖名（`customizeCateName`），C 端与列表展示该名称，平台原名保留；不填则取平台原名 |

### 1.4 与商城运营平台的职责边界

| 维度 | 商城运营平台（商品中心） | 品牌商城后台 |
|------|----------------------|------------|
| 分类结构 | 编排分类结构、关联商品、指定适用渠道 | 接收平台，新增营销分类，编辑名称/图标，隐藏分类 |
| 发布机制 | 草稿/发布隔离，发布推送至品牌商城 | **直接生效**，预览小程序 C 端展示 |
| 删除权限 | 可删除虚拟分类和营销分类 | **不可删除平台分类**（仅可隐藏）；可删除自有营销分类 |
| 新增权限 | 可新增基础分类和营销分类 | **仅可新增营销分类**，不可新增基础分类 |
| 排序 | 设置推荐排序（推送后为初始值） | 可覆盖调整，最终排序以商城侧为准 |
| 修改平台分类 | 全部字段可编辑 | 仅可自定义前端显示名称（`customizeCateName`）与管理本分类商品归属，结构属性不可改 |
| 渠道 | 为分类指定适用渠道 | 不涉及渠道配置，仅管理本商城数据 |

## 2. 功能架构

### 2.1 导航与布局

- **导航**：在系统左侧导航栏设置【前台分类管理】二级菜单，位于"商品管理"分组下。
- **整体布局**：采用"左侧分类树 + 右侧数据表格"布局（与商城运营平台前台分类管理保持一致）。

页面从左到右、从上到下分为以下区域：

| 区域 | 说明 |
|------|------|
| 左侧分类树 | 展示全部分类节点（基础分类 + 营销分类分区展示），顶部提供"全部 / 显示"两种筛选切换；点击节点过滤右侧表格，并记录选中节点供新建时自动填所属上级 |
| 右上角页面标题区 | 【预览】按钮 + 「上次同步时间」文字 |
| 右侧筛选栏 | 分类名称、分类类型、来源、C端展示状态筛选 + 查询/重置按钮（位于操作栏上方） |
| 右侧操作栏 | 左侧【新建营销分类】主按钮；右侧【全部展开 ▾ / 全部收起 ▴】链接（位于筛选栏下方、紧贴表格） |
| 右侧主体 | 统一分类数据表格（树形缩进展示） |

## 3. 核心功能说明

### 3.1 统一分类列表

**功能描述**

品牌商城后台的前台分类管理页面采用**统一列表**（不做基础/营销双Tab），通过"分类类型"列和"来源"列区分不同分类。这是与商城运营平台的核心交互差异。

**列表字段**

| 列 | 说明 |
|----|------|
| 分类名称 | 树形缩进展示（**强制三级结构**：一级=目录、二级=目录、第三级=节点可关联商品），行首展开箭头 + 拖拽手柄（⋮⋮，hover 显示）+ 分类名称。平台分类若已设置自定义显示名，以「自定义名(平台原名)」形式展示。平台数据行使用浅灰色区分 |
| 分类类型 | `基础分类`（蓝）/ `营销分类`（橙） |
| 来源 | `平台`（灰）/ `自有`（绿） |
| 图标 | 缩略图（取分类名首字占位）。**仅第三级节点可上传图标**；一二级目录无图标 |
| 关联商品数 | 格式"在售数/总数"（如 45/58），**第三级节点为蓝色可点击数字**，点击打开「管理分类商品」弹窗（见 3.8）。**仅第三级节点显示商品数**；一二级目录显示"—" |
| 排序 | 数字权重（越小越靠前），支持**行内点击编辑**或**拖拽排序**。商城侧排序为最终排序 |
| C端展示状态 | 开关控件。平台分类：显示/隐藏；自有分类：显示/隐藏 |
| 更新人/时间 | 审计信息，分两行展示（更新人 + 时间） |
| 操作 | 第三级节点（平台/自有均含）：【管理商品】；平台分类另有【编辑】（自定义显示名），自有营销分类另有【编辑】【删除】；一二级目录：平台分类【编辑】、自有营销分类【编辑】【删除】 |

> 说明：商品与分类的关联关系可在本页面通过三级节点的【管理商品】维护（见 3.8）；「商品中心 - 批量映射」上传映射表格可批量自动归属，两条路径并存、数据同源。

### 3.2 接收平台数据

- 商品中心发布更新后，品牌商城后台自动接收新版本平台数据。
- 新推送的分类默认可见（除非商城侧此前已将其隐藏）。
- **商城侧已有的隐藏/排序调整保留**，不被新平台覆盖。

### 3.3 新建营销分类

- 点击操作栏【新建营销分类】，弹出新建弹窗（对齐已开发系统的「自建前台分类」弹窗：仅名称 + 缩略图两个字段，底部取消/确定按钮**居中**）。
- **不可新建基础分类**，弹窗中无此选项。
- 弹窗字段：

| 字段 | 控件 | 必填 | 说明 |
|------|------|:----:|------|
| 分类名称 | 文本输入 | 是 | 限制 30 字以内；输入时实时查重 |
| 分类缩略图 | 图片上传（点击上传，80×80 预览框） | 否 | **仅当新建为第三级节点时显示**；建议尺寸 200*200；一二级目录不显示该字段 |

- **所属上级（隐式）**：弹窗内不显示上级选择控件；新建的分类自动挂载到**当前左侧分类树/表格中选中的自有营销分类**之下（该节点须为一二级）。未选中或选中节点不满足条件时，新建为一级分类。弹窗底部以提示文案告知挂载位置（如"将新建为「员工福利套餐」下的三级节点（可关联商品）"）。
- **节点类型（隐式）**：由挂载层级自动决定，不再显示只读节点类型字段——一级/二级=目录，第三级=节点（可关联商品，可传缩略图）。
- **新建层级约束**：所选上级为一级时新建二级（目录）、为二级时新建三级（节点）；上级已是第三级节点时**禁止新建**，弹窗红字提示"所选上级已是第三级节点，不可继续添加子级"并阻断保存。

- **分类名称查重规则**：
  - **分类名称全局唯一**：平台分类之间、自有分类之间、平台与自有之间，均**不允许重名**（全树范围，含所有层级；忽略大小写、去首尾空格后比对；平台分类按显示名参与比对）。
  - 输入时实时校验，命中重复时输入框下方红色提示"分类名称「XXX」已存在（平台/自有分类均不可重名），请修改"，并**阻断保存**。

### 3.4 平台分类（仅可自定义显示名称 + 管理商品）

- **平台来源的分类，商城侧不可修改其结构属性、不可删除**。分类结构、图标、分类类型、来源、所属上级、适用渠道等字段由商品中心维护，商城侧只读。
- 商城侧可对平台分类执行：**自定义前端显示名称**（见下）、**管理分类商品**（见 3.8，调整本分类下的商品归属）、**隐藏/恢复**（控制 C 端展示状态）、**调整排序**。

**自定义前端显示名称（伪改名）**

| 项 | 说明 |
|----|------|
| 入口 | 操作列【编辑】按钮，打开「编辑(平台)前台分类」弹窗 |
| 弹窗字段1 | 前台分类名称（平台原名，**只读**展示） |
| 弹窗字段2 | 自定义前端显示名称：文本输入，≤30 字，非必填；**不填则取平台原名** |
| 存储方式 | 保存为 `customizeCateName` 覆盖显示层；平台原名 `name` 保留不动（与已开发系统字段一致） |
| 生效范围 | 列表分类名称列、左侧分类树、小程序 C 端（含预览）均展示自定义名；已设置自定义名的行在名称列以「自定义名(平台原名)」形式展示 |
| 平台发布覆盖 | 商品中心再次发布同步更新平台原名与图标，**不覆盖** `customizeCateName` |
| 查重规则 | 显示名全局唯一：全树范围（含所有层级）内，任一分类的显示名（`customizeCateName`，未设置则取 `name`）之间不允许重复；忽略大小写、去首尾空格后比对；命中重复阻断保存并红色提示 |
| 恢复原名 | 清空自定义显示名称保存，即恢复展示平台原名 |

### 3.5 隐藏与恢复

- 商城可隐藏任意平台分类（基础或营销分类），隐藏后 C 端不可见但后台数据保留。
- 隐藏通过操作列或 C 端展示状态开关切换，即时生效。
- 商品中心再次发布时，商城侧隐藏状态保留。
- **不可操作**：商城不可删除平台分类（操作列无删除按钮）。

### 3.6 排序

商城侧提供两种调整排序的方式，调整后直接生效，最终排序以商城侧为准：

| 方式 | 操作 |
|------|------|
| 行内编辑 | 点击「排序」列的数字，切换为数字输入框，输入权重（1~999）后回车或失焦提交；Esc 取消 |
| 拖拽排序 | hover 行首显示拖拽手柄（⋮⋮），按住拖拽至**同级**其他分类上方/下方完成排序。仅允许同级拖拽，跨层级拖拽无效 |

- 拖拽或编辑完成后，受影响同级分类的排序权重按新顺序自动顺延（1,2,3...）。

### 3.7 预览小程序

原型页面右上角提供【预览】按钮，用于在后台直接预览小程序端 C 端的分类展示效果。

- 点击【预览】按钮，弹出「小程序端预览」弹窗。
- 弹窗内渲染一个手机模拟框，模拟小程序分类页：
  - 顶部状态栏 + 标题（商城名称）+ 胶囊按钮。
  - 搜索框占位。
  - 主体为"左侧一级分类 + 右侧内容区"的经典分类页布局：
    - 左侧列出**所有已开启 C 端展示的一级分类**，点击切换。
    - 右侧顶部展示当前分类 Banner，下方以宫格展示子分类（有子级时）或固定分组（全部/精选/热销/新品等，无子级时）。
  - 底部 Tab 栏（首页 / 分类 / 购物车 / 我的），"分类"高亮。
- 预览仅展示**已开启 C 端展示**的分类；隐藏的分类不出现在预览中。
- 无可见分类时，手机框内展示空状态提示"暂无可见分类，请在后台开启分类的C端展示"。
- 弹窗底部居中提示"仅展示已开启C端展示的分类"，右侧【关闭】按钮关闭弹窗。
- 【预览】按钮上方显示「上次同步时间」。

### 3.8 管理分类商品（分类↔商品关联管理）

**功能描述**

在分类管理页直接维护分类下的商品归属：把商品加入某个分类、或把商品移出某个分类。**平台分类与自有分类的三级节点均开放此能力**（商品归属影响本商城 C 端导航，属商城侧经营决策）；一二级目录不挂商品、不提供此入口。

**入口**

| 入口 | 说明 |
|------|------|
| 操作列【管理商品】 | 仅第三级节点显示 |
| 关联商品数列 | 第三级节点的"在售数/总数"为蓝色可点击数字，点击直达 |

**弹窗结构**：标题为「管理分类商品 - {分类显示名}」，内含两个 Tab：

**Tab 1 已在该分类**

| 元素 | 说明 |
|------|------|
| 搜索框 | 按 **SKU名称 / 商城SKU** 模糊过滤当前列表（placeholder 明示字段名） |
| 商品列表 | 商品图、SKU名称、商城SKU（行内标注字段名）、状态（在售/已下架）、价格；每行带勾选框 |
| 批量移出 | 勾选后点击，解除所选商品与本分类的关联；未勾选点击时 Toast 提示"请先勾选要移出的商品" |
| Tab 徽标 | 实时显示当前分类商品总数 |

**Tab 2 添加商品**

| 元素 | 说明 |
|------|------|
| 搜索框 | 按 **SKU名称 / 商城SKU** 模糊搜索本商城商品（placeholder 明示字段名） |
| 商品候选列表 | 展示本商城商品，**排除已在该分类的商品**（避免重复添加）；已下架商品可搜索到、可添加（加入后 C 端不可见，上架后自动展示） |
| 加入分类 | 勾选后点击，建立所选商品与本分类的关联；未勾选点击时 Toast 提示"请先勾选要加入的商品" |

**业务规则**

| 规则编号 | 规则描述 |
|----------|----------|
| RULE-CATE-PROD-001 | 仅第三级节点（可关联商品的层级）可管理商品；一二级目录点击提示"仅三级分类节点可管理商品" |
| RULE-CATE-PROD-002 | 一个商品可同时属于多个分类；加入新分类不影响其已在其他分类的归属 |
| RULE-CATE-PROD-003 | 移出仅解除商品与本分类的关联，不影响商品在其他分类的归属，不下架、不删除商品 |
| RULE-CATE-PROD-004 | 关联变更即时生效，列表"关联商品数"（在售数/总数）与弹窗 Tab 徽标实时刷新 |
| RULE-CATE-PROD-005 | "在售数"口径 = 该分类下上架状态商品数；已下架商品计入总数不计入在售数 |
| RULE-CATE-PROD-006 | 删除自有分类时按 3.10 解除该分类下全部商品关联；平台分类被上游删除时商品归属随分类失效，商品本身不受影响 |
| RULE-CATE-PROD-007 | 商城侧的商品归属调整仅对本商城生效，不同步回商城运营平台 |

### 3.9 编辑自有营销分类

- 仅可编辑来源为"自有"的营销分类：操作列【编辑】打开「编辑营销分类」弹窗（对齐已开发系统的「编辑自建前台分类」）。
- 弹窗字段与新建一致：**分类名称**（必填，≤30 字，实时查重，编辑时排除自身当前名）、**分类缩略图**（仅三级节点显示，回显已传缩略图，可重新上传；建议尺寸 200*200）。
- 不可修改所属上级与层级（结构变更通过删除后重建实现）。
- 底部取消/确定按钮**居中**；保存即时生效并刷新列表、分类树。

### 3.10 删除自有营销分类

- 仅可删除**来源为"自有"的营销分类**。
- 点击操作列【删除】，弹出删除确认弹窗：
  - 警告文案：将删除自有分类「XXX」及其 N 个子级分类（有子级时），并自动解除所有商品关联。
  - 提示：删除后不可恢复，关联商品将被解除关联（有子级时为"子级分类将一并删除"）。
  - 【确认删除】/【取消】。
- 确认后即时删除并刷新列表。

### 3.11 平台更新时的合并规则

| 平台变更 | 商城侧处理 |
|---------|-----------|
| 新增分类 | 默认可见，追加至列表末尾 |
| 删除分类 | 标记为已失效，灰色不可操作 |
| 修改名称/图标 | 同步更新平台原名与图标；商城侧已设置的自定义显示名（`customizeCateName`）**保留不覆盖** |
| 修改商品关联 | 平台侧推送的初始归属自动同步；商城侧通过【管理商品】的后续调整在同步后保留（以商城侧为准） |
| 停用分类 | 商城侧不可访问，操作记录保留 |
| 适用渠道移除本商城 | 分类从导航移除，操作记录保留 |

## 4. 筛选与查询

右侧筛选栏提供以下筛选项，与左侧分类树点击过滤**叠加生效**：

| 筛选项 | 控件 | 说明 |
|--------|------|------|
| 分类名称 | 文本输入 | 模糊匹配分类名称 |
| 分类类型 | 下拉选择 | 全部 / 基础分类 / 营销分类 |
| 来源 | 下拉选择 | 全部 / 平台 / 自有 |
| C端展示状态 | 下拉选择 | 全部 / 显示 / 隐藏 |
| 查询 | 按钮 | 应用筛选条件刷新列表 |
| 重置 | 按钮 | 清空全部筛选条件，恢复全量展示；同时清除左侧分类树选中 |

左侧分类树还提供"全部 / 仅显示"两种树节点筛选切换，控制树中是否展示已隐藏的分类。

## 5. 边界条件与异常处理

| 场景 | 处理规则 |
|------|----------|
| 平台分类被商品中心删除 | 标记为已失效，灰色不可操作 |
| 平台分类被商品中心停用 | 商城侧不可访问，子级同步隐藏 |
| 商品中心发布时商城正在编辑 | 提示"平台数据已更新，请刷新后重新操作" |
| 跨层级拖拽排序 | 拖拽无效，列表顺序不变 |
| 无可见分类时预览 | 手机框展示空状态，引导开启分类 C 端展示 |
| 分类名称重复（平台/自有任意来源） | 阻断保存，红色提示"分类名称「XXX」已存在，请修改"；按**显示名**（自定义显示名，未设置取原名）在全树范围查重，平台与自有之间、各自内部均不可重名 |
| 自定义显示名与其它分类显示名重复 | 阻断保存，红色提示重复项；清空保存则恢复平台原名 |

## 6. 视觉与体验规范

- 与商城运营平台前台分类管理保持**一致的视觉风格和交互模式**。
- 平台数据行使用浅灰色背景区分来源，与自有数据形成视觉差异。
- 分类类型标签颜色与运营平台一致：基础分类（蓝）、营销分类（橙）。
- 来源标签：平台（灰）、自有（绿）。
- 预览弹窗以真实手机外观模拟，C 端元素（Banner、宫格、Tab）按小程序视觉还原。
