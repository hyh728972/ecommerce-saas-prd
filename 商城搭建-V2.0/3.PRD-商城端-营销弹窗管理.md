## 2. 背景与目标

### 2.1 业务背景

商城端在完成「模板选用 → 应用管理」主流程后，运营人员需要一种**轻量、可定向触达**的营销手段，在用户进入商城特定页面时推送活动/商品信息，以提升活动曝光、新客转化与留存。

本次新增「营销弹窗」模块，定位为商城端运营自助配置的**前端弹窗投放工具**，支持按页面、时段、用户、行为等维度精准投放，并在编辑时提供移动端实时预览。

### 2.2 用户故事

| 编号    | 用户故事                                                          |
| ----- | ------------------------------------------------------------- |
| US-01 | 作为**平台运营**，我想要**按名称、状态、投放页面等条件筛选弹窗**，以便快速定位需要管理的弹窗。            |
| US-02 | 作为**平台运营**，我想要**新建弹窗并配置投放时间、页面、跳转目标**，以便在不同场景精准触达用户。           |
| US-03 | 作为**平台运营**，我想要**在编辑弹窗时实时预览移动端效果**，以便上线前确认素材与文案呈现。              |
| US-04 | 作为**平台运营**，我想要**按触发时机、展示频次、目标用户精细化控制弹窗**，以避免打扰用户、提升转化。         |
| US-05 | 作为**平台运营**，我想要**对投放中/待投放的弹窗停用、对已停用的弹窗重新启用**，以便灵活应对业务变化。       |
| US-06 | 作为**平台运营**，我想要**区分草稿与已发布弹窗**，以便先保存配置再择机上线。                     |

### 2.3 产品目标

| 目标项  | 描述                                                                 |
| ---- | ------------------------------------------------------------------ |
| 配置自助化 | 运营可在工作台自助完成弹窗从创建到上线的全流程，无需开发介入                                  |
| 投放精准化 | 支持按页面、时段、用户群、行为触发、展示频次 5 个维度组合投放                                  |
| 上线安全  | 提供移动端实时预览、二次确认启用、停用/重新启用能力，降低错误投放风险                               |
| 状态可观测 | 列表直观展示「投放中 / 待投放 / 已结束 / 草稿 / 已停用」五种状态，并支持按状态过滤                  |

## 3. 名词解释

| 名词     | 含义                                                        |

| 投放页面   | 弹窗在前端展示的页面，当前包含：首页、分类页                                     |

| 实际状态   | 根据 `status` 字段与当前时间动态计算的状态，用于列表展示与操作按钮控制                   |

## 5. 功能详细需求

### 5.1 营销弹窗列表页

#### 5.1.1 页面结构

- 页面标题：**营销弹窗**
- 主操作按钮：**+ 新建弹窗**（页面右上角）
- 查询筛选区（可收起/展开，默认展开）
- 数据表格 + 分页

#### 5.1.2 查询筛选条件

| 字段     | 控件类型     | 选项 / 校验                                | 是否高级（默认收起时隐藏） |
| ------ | -------- | -------------------------------------- | ------------- |
| 弹窗名称   | 文本输入     | 模糊匹配，支持空值                              | 否             |
| 状态     | 下拉选择     | 全部 / 投放中 / 待投放 / 已结束 / 草稿 / 已停用        | 否             |
| 投放页面   | 下拉选择     | 全部 / 首页 / 分类页                          | 否             |
| 目标用户   | 下拉选择     | 全部 / 全部用户 / 新用户 / 老用户 / 特定用户           | 否             |
| 跳转行为   | 下拉选择     | 全部 / 活动页 / 商品详情                        | 是             |
| 投放开始时间 | 日期选择     | 按弹窗 `timeStart` 过滤                     | 是             |
| 投放结束时间 | 日期选择     | 按弹窗 `timeEnd` 过滤                       | 是             |

操作按钮：
- **查询**：按当前条件刷新列表
- **重置**：清空所有筛选条件
- **收起/展开**：切换高级筛选项的显示

#### 5.1.3 列表字段

| 列名   | 取值规则                                            | 说明                          |
| ---- | ----------------------------------------------- | --------------------------- |
| 弹窗名称 | `name`                                          | 文本                          |
| 投放时间 | `timeStart ~ timeEnd`，格式 `yyyy-MM-dd HH:mm`     | 范围展示                        |
| 投放页面 | `deliveryPages` 数组**仅取第一个**元素的标签；无值显示 `-`        | 当前实现为单选，仅显示首个               |
| 跳转页面 | `jumpPageLabel`                                 | 跳转目标名称；无值显示 `-`             |
| 状态   | 由 `getEffectiveStatus` 计算的实际状态                  | 标签形态：投放中/待投放/已结束/草稿/已停用     |
| 操作   | 根据实际状态动态生成                                      | 见 5.1.5                     |

#### 5.1.4 实际状态计算规则

输入为弹窗的 `status` 字段与当前时间，输出实际状态：

| `status` | 时间条件                          | 实际状态     |
| -------- | ----------------------------- | -------- |
| `draft`  | —                             | 草稿       |
| `paused` | —                             | 已停用      |
| `active` | `now > timeEnd`               | 已结束      |
| `active` | `now < timeStart`             | 待投放      |
| `active` | `timeStart ≤ now ≤ timeEnd`   | 投放中      |
| `scheduled` | `now > timeEnd`            | 已结束      |
| `scheduled` | 其他                         | 待投放      |

#### 5.1.5 操作按钮（按实际状态）

| 实际状态 | 操作按钮                          |
| ---- | ----------------------------- |
| 草稿   | 启用 / 详情 / 删除                  |
| 投放中  | 停用 / 详情                       |
| 待投放  | 停用 / 详情                       |
| 已停用  | 重新启用（仅当 `now < timeEnd`）/ 详情 / 删除 |
| 已结束  | 详情 / 删除                       |

#### 5.1.6 分页

- 当前原型仅展示总数 `共 N 条`，未做页码分页（数据量小，全部展示）
- 后续数据量增大时需补充分页参数（页码、每页条数）

#### 5.1.7 空状态

- 列表无数据时，显示「暂无弹窗数据」，占据整行（`colspan=6`）

### 5.2 新建/编辑弹窗表单

#### 5.2.1 表单结构

弹窗式编辑器，整体分为两栏：

- **左侧：表单主区**（`.popup-form-main`）
- **右侧：移动端实时预览**（`.popup-form-preview-panel`），可一键关闭/打开

底部操作按钮：**关闭预览** / **取消** / **保存草稿** / **保存并启用**

#### 5.2.2 表单字段定义

| 字段     | 必填 | 控件类型             | 校验规则                                                    |
| ------ | -- | ---------------- | ------------------------------------------------------- |
| 弹窗名称   | 是  | 文本输入（maxlength=50） | 非空                                                       |
| 投放时间   | 是  | 日期时间范围（起 ~ 止）     | 起止均非空，且 `timeStart < timeEnd`                            |
| 投放页面   | 是  | **单选**（radio）     | 非空；选项：首页 / 分类页                                          |
| 跳转行为   | 是  | 单选（radio）        | 默认「活动页」；可选「商品详情」                                        |
| 跳转页面   | 是  | 下拉 / 商品搜索        | 跳转行为为「活动页」时下拉选择活动；为「商品详情」时弹出商品搜索                         |
| 触发时机   | 是  | 单选 + 子配置         | 进入页面 N 秒（默认 3，1~60）/ 用户行为（加购 / 浏览 N 秒，默认 10，1~300）       |
| 展示频次   | 是  | 单选按钮组             | 每次 / 每天 / 每周 / 仅首次 / 自定义（间隔 N 分钟，默认 60，1~999）            |
| 目标用户   | 是  | 单选按钮组 + 子配置       | 全部用户（默认）/ 新用户 / 老用户 / 特定用户（需搜索选择用户，支持多选）                |
| 是否延时关闭 | 否  | 单选按钮组（否/是）+ 子配置   | 选「是」时显示「倒计时 N 秒」输入框（默认 5，3~30）；选「否」时不延时                  |
| 弹窗素材   | 是  | 分段控件 + 上传/素材库    | 二选一；上传需选择图片；素材库需选择一张图片                                   |

> **关闭方式说明**：点击蒙层关闭、关闭按钮关闭为**默认固定开启**的行为，不在表单中显式配置；运营仅通过「是否延时关闭」控制是否启用倒计时关闭。

#### 5.2.3 弹窗素材

支持两种来源：

1. **上传图片**
   - 支持点击/拖拽上传
   - 建议 600×800，JPG / PNG
   - 上传后支持「重新上传」
2. **素材库**
   - 点击「从素材库选择」打开素材库弹窗
   - 网格展示素材缩略图，单选
   - 选中后展示缩略图 + 素材名称 + 「更换素材」按钮

#### 5.2.4 移动端实时预览

预览面板包含：

- 手机外壳模拟（含刘海、状态栏）
- 顶部页面名称（默认「首页」，可通过下方 Tab 切换：首页/分类/商品/活动/我的）
- 页面骨架占位（banner、icon、card 等）
- 弹窗蒙层 + 弹窗主体（图片素材）
- 弹窗关闭按钮（受「关闭按钮」开关控制 —— 当前固定显示）
- 倒计时文案（受「是否延时关闭」控制 —— 选「是」时显示 `Ns 后关闭`）

**联动规则**：
- 切换弹窗素材来源、上传/选择图片 → 实时更新预览图
- 切换「是否延时关闭」→ 实时显示/隐藏倒计时文案
- 切换关闭按钮 → 实时显示/隐藏关闭按钮（当前固定为显示）

#### 5.2.5 提交逻辑

- **保存草稿**：`status = draft`，不校验投放时间是否晚于当前
- **保存并启用**：`status = active`，所有必填项校验通过后保存
  - 启用后实际状态由 `timeStart`/`timeEnd` 与当前时间动态决定（投放中/待投放/已结束）

#### 5.2.6 校验失败提示（alert）

| 触发条件                          | 提示文案         |
| ----------------------------- | ------------ |
| 弹窗名称为空                        | 请填写弹窗名称。     |
| 投放时间为空                        | 请设置投放时间。     |
| `timeStart >= timeEnd`        | 投放结束时间须晚于开始时间。 |
| 投放页面未选                        | 请至少选择一个投放页面。 |
| 跳转行为=商品详情但未选商品                | 请搜索并选择一个商品。  |
| 目标用户=特定用户但未选                  | 请搜索并选择至少一位特定用户。 |
| 素材来源=上传但未上传（新建时）              | 请上传弹窗图片。     |
| 素材来源=素材库但未选                   | 请从素材库选择图片。   |

### 5.3 弹窗详情

点击列表「详情」按钮打开，只读展示该弹窗全部配置：

- 弹窗名称、状态、投放时间、投放页面、跳转行为、跳转页面
- 触发时机、展示频次、目标用户（含特定用户 ID）
- **关闭方式**：选「是」显示「倒计时 N 秒」，选「否」显示「否」
- 弹窗素材：缩略图 + 素材名称

底部操作：**关闭**

---

### 5.4 状态管理操作

#### 5.4.1 启用（草稿 → 投放中/待投放）

- 操作入口：列表「启用」按钮
- 行为：将 `status` 由 `draft` 改为 `active`，实际状态由时间决定

#### 5.4.2 停用（投放中/待投放 → 已停用）

- 操作入口：列表「停用」按钮
- 行为：将 `status` 改为 `paused`

#### 5.4.3 重新启用（已停用 → 投放中/待投放）

- 操作入口：列表「重新启用」按钮
- 仅当 `now < timeEnd` 时显示该按钮；`now ≥ timeEnd` 时不显示（已结束无法启用）
- 行为：将 `status` 由 `paused` 改为 `active`

#### 5.4.4 删除

- 操作入口：列表「删除」按钮
- 适用状态：草稿、已停用、已结束
- 行为：从列表移除该弹窗（原型为前端数据，无二次确认；正式环境建议增加二次确认）

### 6.2 枚举映射

- **投放页面** `POPUP_DELIVERY_PAGE_LABELS`：home→首页、category→分类页、cart→购物车、mine→我的
- **跳转行为** `POPUP_JUMP_BEHAVIOR_MAP`：activity→活动页、product→商品详情
- **展示频次** `POPUP_FREQUENCY_MAP`：every→每次打开页面都触发、daily→每自然日首次触发、weekly→每自然周首次触发、first→账号生命周期只弹一次、custom→自定义
- **目标用户** `POPUP_TARGET_MAP`：all→全部用户、new→新用户、old→老用户、specific→特定用户
- **状态** `POPUP_STATUS_MAP`：active→投放中、scheduled→待投放、ended→已结束、draft→草稿、paused→已停用

## 8. 异常与边界

| 场景                        | 处理                                                   |
| ------------------------- | ---------------------------------------------------- |
| 投放结束时间早于或等于开始时间           | 阻止提交，提示「投放结束时间须晚于开始时间」                                |
| 已停用弹窗的 `timeEnd` 已过       | 列表不显示「重新启用」按钮；仅显示「详情 / 删除」                            |
| 编辑器中切换跳转行为                | 跳转目标控件联动切换：活动页 → 下拉；商品详情 → 搜索                         |
| 编辑器中切换触发时机                | 子配置联动：进入页面 → 显示延迟秒数输入；用户行为 → 显示行为下拉 + 浏览秒数输入          |
| 编辑器中切换目标用户为「特定用户」         | 显示用户搜索区，支持搜索姓名/手机号，选中后以标签展示，支持移除                     |
| 编辑器中切换展示频次为「自定义」          | 显示「间隔 N 分钟再次弹窗」输入                                     |
| 编辑器中切换「是否延时关闭」为「是」        | 显示「倒计时 N 秒」输入并启用；切回「否」则隐藏并禁用                          |
| 列表筛选结果为空                  | 显示「暂无弹窗数据」整行占位                                        |
| 上传图片超大或格式不符               | 原型未做限制，正式环境需限制大小 ≤ 2MB、格式 JPG/PNG                     |
