# 商城端运营工作台 PRD

**文档版本**：v1.0  
**对应原型**：`7.商城端工作台-原型`（`index.html`、`editor.html`、`movie-ticket-card-prototype.html`）  
**说明**：本文档依据当前静态原型中的界面结构与交互逻辑整理，实施时需与后端、权限与小程序端能力对齐。

## 1. 产品概述

### 1.1 背景与目标

面向**平台运营人员**提供「商城端」运营工作台，用于：

- 浏览与筛选**已上架模板**，预览效果并一键进入**模板编辑器**进行配置；
- 管理基于模板创建的**我的应用（商城实例）**，控制**线上可见的已发布应用**（全平台同时仅允许一个处于已发布）；
- 通过独立原型页演示**电影票次卡**在运营后台的批次管理能力（与商城搭建可视为不同子产品/模块）。

### 1.2 术语

| 术语 | 说明 |
|------|------|
| 模板 | 平台侧维护的商城装修模板，含页面结构与组件配置；状态含草稿、已发布、已推送等。 |
| 我的应用 / 商城应用 | 运营基于某模板创建的一条应用记录，关联品牌等信息；状态为草稿或已发布。 |
| 页面类型 | 如首页、分类页、活动页、我的页、商品详情页等（数据与编辑器能力中体现）。 |
| 分类页模板 | 分类页的多种布局范式（如三级分类、二级分类、带商品列表、横向 Tab 等）。 |

## 3. 信息架构（IA）

```
商城端 - 运营工作台
├── 模板列表
│   ├── 筛选（标签）
│   ├── 搜索（模板名称）
│   ├── 模板卡片列表 + 分页
│   └── 卡片操作：预览、使用
├── 我的应用
│   ├── 搜索（商城名称或品牌）
│   ├── 应用卡片列表 + 汇总条数
│   ├── 「+ 新建商城」
│   └── 卡片操作：预览、编辑、发布（草稿可点）
└── 全局/跨页弹窗
    ├── 发布前预览（模板）
    ├── 选择分类页模板（进入编辑前）

```

**独立页面**：

- `editor.html`：模板/页面**可视化编辑器**（新窗口打开，URL 带 `id`、`name`、`categoryTemplate` 等参数）。
- `movie-ticket-card-prototype.html`：**电影票次卡**运营端（顶部导航 + 侧栏 + 多子页），与商城 IA 并列，不作为「商城端」子菜单。

## 4. 功能需求

### 4.1 模板列表

**入口**：侧栏「模板列表」，`/#` 切换至 `#page-templates`。

**目标**：展示**已发布/已推送**的模板，供运营检索与选用。

#### 4.1.1 列表与数据规则（原型）

- 列表数据仅展示 `status` 为「已发布」或「已推送」的模板（二者在列表展示上均按已发布样式处理）。
- 每条模板展示：名称、标签、最近修改时间、封面预览图（按标签生成差异化配色的小程序首页示意）。
- 列表上方提示文案：**「以下为已发布的模板，可直接选择使用」**。

#### 4.1.2 筛选与搜索

| 能力 | 说明 |
|------|------|
| 标签筛选 | 下拉选项：全部、美妆、食品、服饰、618大促；按模板 `tags` 包含关系过滤。 |
| 名称搜索 | 输入框占位「搜索模板名称…」，支持按钮「搜索」与输入框回车；对名称做不区分大小写的包含匹配。 |
| 重置 | 清空标签与关键词，恢复默认列表。 |

#### 4.1.3 分页

- 前端分页，每页 **5** 条。
- 展示总条数、「上一页」、页码按钮、「下一页」；边界页禁用对应翻页按钮。

#### 4.1.4 卡片操作

| 操作 | 行为（原型） |
|------|----------------|
| 预览 | 弹出提示，说明实际可新窗口打开预览 URL。 |
| 使用 | 打开 `editor.html` 新窗口，并传入模板 `id` 与名称等查询参数。 |

---

### 4.2 我的应用

**入口**：侧栏「我的应用」，切换至 `#page-mall-list`。

**目标**：管理由模板衍生的**商城应用**；业务规则：**同一时刻全列表仅允许一个应用为「已发布」**，其余为「草稿」。

#### 4.2.1 列表展示

- 上方说明：**「应用基于模板创建：仅一个应用处于「已发布」，其余为「草稿」」**。
- 每条应用展示：应用名称、模板标签（继承自关联模板）、创建时间、封面（继承关联模板预览图）。
- 状态角标：**已发布** / **草稿**。

#### 4.2.2 搜索

- 占位：**「搜索商城名称或品牌…」**。
- 对应用名称、品牌名称做不区分大小写的包含匹配。

#### 4.2.3 新建商城

- 按钮「+ 新建商城」：原型为弹窗/向导占位提示；产品上可扩展为选择模板、填写应用名、品牌等。

#### 4.2.4 卡片操作

| 操作 | 行为（原型） |
|------|----------------|
| 预览 | 提示预览关联模板。 |
| 编辑 | 以关联 `templateId` 打开编辑器新窗口。 |
| 发布 | 仅草稿可用；打开**二次确认弹窗**（见 4.4.3）。确认后：将目标应用设为已发布，**其余已发布应用全部降级为草稿**。 |

---

### 4.3 弹窗与流程

#### 4.3.1 发布前预览（模板）

**触发**：代码中存在打开发布预览弹窗的逻辑（`openPublishPreview`）；界面含「发布前预览」标题。

**内容**：

- 提示：请在 **PC 与移动端** 预览无误后再发布（原型中 PC Tab 可注释，保留「移动端预览」）。
- 预览区域为演示占位；底部「返回编辑」「确认发布」——确认后原型提示已发布并应刷新列表（实际需写库与审计）。

#### 4.3.2 选择分类页模板

**触发**：在「页面管理」相关流程中，当新建页面类型为**分类页**时，需先选择布局（`openCategoryTemplate` / `confirmCategoryTemplate`）。

**可选布局（单选）**：

1. **三级分类页**：左侧一级 + 右侧二级分组与三级图标网格  
2. **二级分类页**：左侧一级 + 右侧二级图标网格（无分组标题）  
3. **二级分类 + 商品列表页**：左侧一级 + 右侧 Tab 子分类 + 商品列表  
4. **一级分类 + 商品分类页（横向 Tab）**：顶部横向 Tab + 商品列表  
5. **一级分类 + 商品分类页（直接列表）**：左侧一级 + 右侧直接商品列表  
6. **一级分类 + 商品分类页（直接列表样式二）**：同上路径，另一种卡片样式  

**确认后**：新开编辑器窗口，`id=new`，并附带 `categoryTemplate` 参数；页面标题形如「新建分类页 - {布局名称}」。

#### 4.3.3 确认发布应用（我的应用）

- 标题：**确认发布**。  
- 文案：确定将该应用设为「已发布」吗？**其他已发布应用会变为「草稿」。**  
- 按钮：取消、确定发布；确定后执行 4.2.4 中发布规则。

### 4.4 编辑器（`editor.html`）— 能力纲要

原型为**大型单页**，包含左中右布局、可拖拽宽窄、中间手机/PC 画布、右侧属性配置等。以下按产品能力归纳（非穷尽每一控件）。

#### 4.4.1 布局与设备

- **三栏结构**：左侧（页面/楼层列表与页签切换）、中部（画布与手机壳或 PC 宽度模式）、右侧（配置面板）；左右栏宽可拖拽调整。
- **设备模式**：支持移动端竖屏壳与 **PC 模式**（`editor-phone-shell.pc-mode` 等），用于预览不同宽度。

#### 4.4.2 页面与楼层

- 支持多页面管理（页面名称编辑、默认页标识、删除入口等 UI）。
- 画布以**楼层（floor）**为单位堆叠；楼层可拖拽排序、选中高亮、侧栏快捷操作（投放、复制、删除等在原型/数据层有占位）。
- **页面类型维度**（与 `data.js` 中 `MOCK_TEMPLATE_PAGES` 一致）：首页、分类页、活动页、我的页、商品详情页等。

#### 4.4.3 组件/楼层类型（样式类名与区块体现）

原型中间画布与左侧列表涵盖多种区块，包括但不限于：

- 轮播/横幅（banner）、宫格、富文本、类目入口、营销位、**搜索栏（含热词轮播等）**、**公告/跑马灯**、图片滑动、金刚区、标题栏、视频卡、优惠券条、限时抢购列表、**定位条**、**热区**、**自由搭建**、**分类橱窗（category-showcase）**、**商品详情骨架** 等。

分类页在画布上可有 **category-showcase-mode**，与所选「分类页模板」编排一致。

#### 4.4.4 与运营工作台联动

- 从模板列表「使用」或我的应用「编辑」打开：`editor.html?id=…&name=…`；分类页新建附加 `categoryTemplate`。
- 编辑器可向父窗口暴露 `addMallFromTemplate`（原型中用于从编辑页**生成「我的应用」记录**：可选择保存草稿或发布，发布时遵守「仅一个已发布应用」规则）。

### 4.5 电影票次卡运营端（`movie-ticket-card-prototype.html`）

独立** SAAS 后台**样式原型，与「商城端」工作台视觉同一类但不共用侧栏。

#### 4.5.1 顶栏与导航

- Logo：「SAAS后台」；主导航示例：**首页**、**次卡管理**（当前激活）。
- 右上角用户名（示例：张伟）。

#### 4.5.2 次卡管理侧栏

- **批次管理**（列表主流程）  
- **新增批次**  
- **批次列表明细**

#### 4.5.3 批次管理页（列表）

- 面包屑：首页 / 次卡管理 / 批次管理。  
- 标题：**次卡批次管理**；主按钮「+ 新增批次卡」跳转至新增页。  
- 筛选区字段（原型占位）：批次号、状态（全部/正常/作废）、面值、单次使用上限金额等。  
- 数据表格 + 行内操作（查看/编辑等，随原型扩展）。  
- 底部分页区域。

#### 4.5.4 其他子页

- **新增批次**：表单分区、单选/多选、保存与返回等（见原型内表单结构与 `footer-actions`）。  
- **批次列表明细**：明细列表/导出菜单（原型含导出下拉、复制提示等交互占位）。

> **说明**：该模块与「商城模板/应用」无数据耦合；若同一运营后台整合，需在信息架构层做产品线划分或权限划分。

## 5. 数据模型（与原型 Mock 对齐）

### 5.1 模板 `MOCK_TEMPLATES`

- 字段示例：`id`、`name`、`status`（`draft` | `published` | `pushed`）、`tags[]`、`updatedAt`、`useCount`。  
- 列表可见性：**仅 published / pushed 出现在模板列表**。

### 5.2 我的应用 `MOCK_MALLS`

- 字段：`id`、`name`、`brandName`、`templateId`、`status`（`draft` | `published`）、`createdAt`。  
- **约束**：同一数据集内**最多一条** `status === 'published'`。

### 5.3 模板下页面 `MOCK_TEMPLATE_PAGES`

- 按 `templateId` 分组；每页含 `id`、`title`、`type`（`home` | `category` | `activity` | `mine` | `product-detail`）、`status`、`updatedAt`。  
- 列表中「使用中」标识与**同类型下排序第一且已发布**相关（原型展示逻辑）。

### 5.4 其它

- `MOCK_BRANDS`、`MOCK_PUSH_RECORDS`：用于推送、审计类演示；若产品上保留「推送给品牌方」，需定义推送类型（仅模板 / 模板+数据）与品牌多选。

## 6. 业务规则汇总

| 编号 | 规则 |
|------|------|
| R1 | 模板列表仅展示对已运营可见的已发布/已推送模板。 |
| R2 | 我的应用中，**全平台（或当前租户）同时仅允许一个应用为「已发布」**；发布新应用时，原已发布应用自动变为草稿。 |
| R3 | 新建分类页必须先选择六种分类页模板之一，再进入编辑器。 |
| R4 | 模板/应用上的「预览」在实作应支持真实预览链接或二维码，原型仅为提示。 |

## 7. 非功能需求（建议）

| 类别 | 要求 |
|------|------|
| 兼容性 | 编辑器与后台建议支持现代浏览器；原型大量依赖前端脚本。 |
| 审计 | 模板发布、应用发布、推送品牌等操作应记录操作者、时间（原型为 alert）。 |
| 安全 | 编辑器内容、图片与跳转链接需 XSS 与协议白名单策略；服务端校验权限。 |
| 性能 | 模板/应用列表服务端分页与图片 CDN；编辑器按需加载楼层配置。 |

## 8. 原型局限（不适配直接投产部分）

- 多处交互以 `alert` 与内存数据模拟，无真实接口。  
- 「新建商城」「推送记录」「页面管理」部分 DOM 或逻辑在 `index.html` 片段中可能不全量展示，以 `app.js` 内函数为准。  
- `movie-ticket-card-prototype.html` 为独立业务线示意，与商城数据未打通。
