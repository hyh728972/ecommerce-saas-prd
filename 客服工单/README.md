# 客服工单 — 开发交付包

> 打包日期: 2026-09-01 · 来源: 在线客服-V1.0(与 OCS 仓库 main 同步)

## 一、范围(1期)

工单列表 / 工单详情 / 工单创建(三模式) / 工单配置 / 会话创建工单入口(工作台+会话记录) / 订单批量建单入口 / 发起售后·发起补偿跳转。
**不含**: 消费者自助建单(2期)、催办与回复用户(2026-09-01 移除,见 PRD V0.8)、AI 类(3期)。

## 二、必读顺序

1. `PRD/PRD-客服工单-V0.8.md` — 现行主 PRD(数据库/API/状态机/交付项以此为准)
2. `PRD/PRD-后台-V0.9.md` — 底座依赖(通知/角色/会话基础设施)
3. `PRD/PRD-工作台转工单-V0.1.md` + `PRD/PRD-会话记录创建工单-V0.1.md` — 两个建单入口的增量定义
   (⚠️ 两份增量稿术语仍为「转工单」,现行口径统一叫「创建工单」,内容以主 PRD V0.8 为准)
4. 原型从 `原型/admin/admin-ticket.html` 进入(浏览器直接开,静态页,mock 数据)

## 三、原型文件

| 文件 | 作用 |
|---|---|
| admin-ticket.html | 工单列表(状态分栏/筛选/倒计时/导出) |
| admin-ticket-detail.html | 工单详情(跟进/附件/完工) |
| admin-ticket-create.html | 建单页(standalone/order/batch/session 四模式) |
| admin-ticket-settings.html | 工单配置(三级分类/责任方/优先级/期限值) |
| admin-order-list.html | 订单列表(工具栏「批量创建工单」) |
| admin-workbench.html | 客服工作台(顶栏「创建工单」抽屉) |
| admin-session-record.html | 会话记录(行内「创建工单」) |
| admin-after-sale.html / admin-compensation.html | 发起售后/补偿跳转占位 |

共享运行时在 `js/` `modals/` `styles.css` `nav.js`,与在线客服主原型同源。
