客服工单 — 开发交付原型

打包日期 2026-09-01 · 源自 在线客服-V1.0(与 OCS main 同步) · 本包仅含客服工单 1 期范围,不含在线客服其余模块
主 PRD:PRD-客服工单-V0.8.md(数据库/API/状态机/交付项以此为准) · 静态原型,mock 数据,浏览器直接打开
核心页面 工单模块本体 · 新建 4 页
1工单列表 admin-ticket.html
状态分栏 / 三级分类筛选 / 完成期限筛选 / 倒计时列 / 导出(仅主管)
行操作按状态:处理中=详情·编辑·发起售后·发起补偿(平铺);未处理/已完工仅详情
2工单创建 admin-ticket-create.html
standalone / order / batch / session 四模式 · 会话与订单上下文预填 · 三级级联 · 批量追加订单
3工单详情 admin-ticket-detail.html
工单跟进(首次跟进自动受理) / 附件 / 倒计时 / 收货信息独立分组
底栏:处理中=发起售后·发起补偿·完工;已完工终态只读
4工单配置 admin-ticket-settings.html
三级分类 / 责任承担方 / 优先级 / 完成期限值(单位天,正整数) 增删改 · 仅主管可配
建单入口 三个来源 · 改现有 3 页
①客服工作台 admin-workbench.html
选中会话 → 顶栏「创建工单」→ 右侧抽屉建单(会话不中断) · 反馈方式默认「在线客服会话」
其余工作台功能不在本包范围
②会话记录 admin-session-record.html
行操作「创建工单」→ 跳建单页 mode=session,带会话上下文(离线待处理行无此按钮)
③订单列表 admin-order-list.html
工具栏「批量创建工单」(勾选 ≥1 单,多单合并一张) → 建单页 mode=batch 自动带出订单信息
↗售后/补偿占位 admin-after-sale.html
工单「发起售后」「发起补偿」的跳转目标占位页
售后不带字段(C2);补偿携带工单号 · 2 期 OMS 集成后回写
PRD 必读顺序 见包根 ../../PRD/ 目录(即交付包的 PRD 文件夹)
  • 1PRD-客服工单-V0.8.md现行主 PRD — 状态机 / 五表 / API 清单 / 交付项路线,一切以此为准
  • 2PRD-后台-V0.9.md底座依赖 — 通知 / 角色 / 会话基础设施(工单为 V0.9 的迭代增量)
  • 3PRD-工作台转工单-V0.1.md建单入口①的增量定义(⚠️ 术语为旧「转工单」,现行口径「创建工单」)
  • 4PRD-会话记录创建工单-V0.1.md建单入口②的增量定义
